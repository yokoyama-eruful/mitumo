# 総合地震特約おすすめ契約計算式一覧

## 共済金支払最大額

### 地震引受限度額

- 地震特約縮小支払割合[DB]が入力されてる
    >建物共済掛金[DB] x 地震特約縮小支払割合[DB] / 100
- それ以外
    >空文字

## 地震掛金(分割も考慮)

### 地震特約加入可不可判定(地震掛金)

- 短期率が0かつ物件が住宅ではない
    > OK(true) </br>
    > 地震掛金(分割考慮)
- それ以外
    > NG(false) </br>
    > 「地震特約加入不可」

### 地震掛金分割考慮

- 払込方法が「分割払」
    > 地震掛金 /12 = １月分の地震掛金 (※小数点2位を切り捨て)　</br>
    > 1月分の地震掛金を小数点1位を切り上げ </br>
    > 1月分の地震掛金の一の位を四捨五入する
- それ以外
    > 地震掛金

### 地震掛金

> 地震引受限度額 x 地震掛金料率[csv] = 地震掛金 (※小数点第1位を切りあげ)</br>
> 地震掛金を小数第1位で四捨五入
>※地震掛金料率[csv]はすべて「2.42」

### 総合合計

>総合建物掛金 + 総合家財掛金 + 総合設備・什器等掛金 + 商品・製品等掛金 ※１の位で四捨五入

### その他割引の計算

DBはデータベースに入る値
CSVはCSVのテーブルから取得する値（物件情報,級別,築年数）※動産は築年数が不要

- 基本形
    > ( **基本率** + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB] ※小数点第 2 位に四捨五入

- 物件情報が「住宅」「普通」の**建物**その他割引
    > ( 建物の基本率[CSV] + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB]

- 物件情報が「工場」の**建物**その他割引
    > ( 建物の基本率[DB] + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB]

- 物件情報が「住宅」「普通」の**動産**その他割引
    > ( 動産の基本率[CSV] + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB]

- 物件情報が「工場」の**動産**その他割引
    > ( 動産の基本率[DB] + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB]

### 適用率

CSV1はCSVのテーブルから取得する値（物件情報,級別,築年数）※動産は築年数が不要
CSV2はCSVのテーブルから取得する値（物件情報,級別,築年数）※動産は築年数が不要

- 基本形
    > **ここが変わる** x 長期率[CSV1] x 短期率[CSV2]
- 建物適用率
     >  (建物その他割引 x 実損払係数[DB]) x 長期率[CSV1] x 短期率[CSV2]
- 家財適用率
     >  (動産その他割引) x 長期率[CSV1] x 短期率[CSV2]
- 設備・什器等適用率
     >  (動産その他割引 x 実損払係数[DB]) x 長期率[CSV1] x 短期率[CSV2]
- 商品・製品等適用率
     > (動産その他割引 + 動産割増[DB]) x 長期率[CSV1] x 短期率[CSV2]

### 掛金

- 基本形
    > **共済掛金** x **適用率**
- 総合建物掛金
    > 建物共済掛金[DB] x 建物適用率
- 総合家財掛金
    > 家財共済掛金[DB] x 家財適用率
- 総合設備・什器等掛金
    > ( 設備・什器等共済掛金[DB] + 設備・什器等その他共済掛金[DB] ) x 設備・什器等適用率
- 商品・製品等掛金
    > ( 商品・製品等共済掛金[DB] + 商品・製品等その他共済掛金[DB] ) x 商品・製品等適用率

## 合計掛金

### 地震特約加入可不可判定(合計掛金)

- 短期率が0かつ物件が住宅ではない
    > OK(true) </br>
    > 地震最大支払額可不可判定
- それ以外
    > NG(false) </br>
    > 「地震特約加入不可」

### 地震最大支払額可不可判定  (※普通地震との差は共済掛金合計のみ)

- 地震支払最大額に値が入っている
    > 総合共済掛金合計 + 地震掛金
-それ以外
    > ''
