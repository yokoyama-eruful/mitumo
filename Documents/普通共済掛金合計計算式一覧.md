# 普通共済掛金に関する計算式一覧

## 普通共済掛金の算出手順

  普通共済掛金の算出は以下のフローに従ってください

### 振込方法が分割払いの場合

> 普通共済掛金を「普通合計(分割)」としてください

### 振込方法が一時払い・長期年払い場合

- 普通合計２の値が0の場合
    >  普通共済掛金を「0」としてください
- 長期年払いフラグがOKだった場合
    >  普通共済掛金を「長期年払いを考慮した普通合計」としてください
- 普通合計２の値が2000より大きい場合
    >  普通共済掛金を「普通合計２」としてください
- 普通合計２の値が2000以下の場合
    >  普通共済掛金を「2000」としてください

***

### 普通合計１ (建物掛金等の説明は下記で説明)

> 普通建物掛金 + 普通家財掛金 + 普通設備・什器等掛金 + 商品・製品等掛金

### 普通合計２

- 一時払い・長期年払い
    > 「普通合計１」の値が適用される
- 分割払い　（10万以上時は普通合計１の値に係数1をかけ、10万未満時は普通合計１の値に係数1.1をかけ）
  - 普通合計１の値が100000以上（10万以上）
    > 普通合計１* 1 / 12 = 1月分の普通合計１(※小数点1位の切り上げ)　</br>
    > 1月分の普通合計１の一の位を四捨五入する
  - 普通合計１の値が100000未満（10万未満）
    > 普通合計１* 1.1 / 12 = 1月分の普通合計１(※小数点1位の切り上げ)　</br>
    > 1月分の普通合計１の一の位を四捨五入する

### 普通（分割）

- 一時払い・長期年払い
    > 「0」
- 分割払い
  - 普通合計２の値が180以上
    > 「普通合計２」の値が適用される
  - 普通合計２の値が180未満
    > 「180」

### 長期年払いフラグ

- 長期年払い かつ 共済期間が5年以上 かつ その他割引が0.1未満
    > OK(true)
- それ以外
    > NG(false)

### 長期年払いを考慮した普通合計

- 普通合計２の値が2050より大きければ
    > 普通合計２ * 0.97 (※1の位で切り上げ) </br>
    > 上記値を十の位で四捨五入
- 普通合計２の値が2050以下
  - 普通合計２の値が2000以上
    > 普通合計２の値が適用される
  - 普通合計２の値が2000未満
    > 2000

***

### その他割引の計算

DBはデータベースに入る値
CSVはCSVのテーブルから取得する値（物件情報,級別,築年数）※動産は築年数が不要

- 基本形
    > ( **基本率** + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB]

- 物件情報が「住宅」「普通」の**建物**その他割引
    > ( 建物の基本率[CSV] + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB]

- 物件情報が「工場」の**建物**その他割引
    > ( 建物の基本率[DB] + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB]

- 物件情報が「住宅」「普通」の**動産**その他割引
    > ( 動産の基本率[CSV] + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB]

- 物件情報が「工場」の**動産**その他割引
    > ( 動産の基本率[DB] + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB]

### 適用率

CSV1はCSVのテーブルから取得する値（物件情報,級別,築年数）※動産は築年数が不要
CSV2はCSVのテーブルから取得する値（物件情報,級別,築年数）※動産は築年数が不要

- 基本形
    > **ここが変わる** x 長期率[CSV1] x 短期率[CSV2]
- 建物適用率
     >  (建物その他割引 x 実損払係数[DB]) x 長期率[CSV1] x 短期率[CSV2]
- 家財適用率
     >  (動産その他割引) x 長期率[CSV1] x 短期率[CSV2]
- 設備・什器等適用率
     >  (動産その他割引 x 実損払係数[DB]) x 長期率[CSV1] x 短期率[CSV2]
- 商品・製品等適用率
     > (動産その他割引 + 動産割増[DB]) x 長期率[CSV1] x 短期率[CSV2]

### 掛金

- 基本形
    > **共済掛金** x **適用率**
- 普通建物掛金
    > 建物共済掛金[DB] x 建物適用率
- 普通家財掛金
    > 家財共済掛金[DB] x 家財適用率
- 普通設備・什器等掛金
    > ( 設備・什器等共済掛金[DB] + 設備・什器等その他共済掛金[DB] ) x 設備・什器等適用率
- 商品・製品等掛金
    > ( 商品・製品等共済掛金[DB] + 商品・製品等その他共済掛金[DB] ) x 商品・製品等適用率
