# 総合おすすめ契約計算式一覧

## おすすめ契約の共済掛金の算出手順

  おすすめ契約の算出は以下のフローに従ってください

### おすすめ契約の共済掛金の計算

不動産(建物)の計算 + 動産(家財)の計算 + 動産(設備・什器等)の計算 + 動産(商品・製品等)の計算

- 不動産(建物)の計算
    >建物共済掛金(DB) x 建物適用率

- 動産(家財)の計算
    >家財共済掛金(DB) x 家財適用率

- 動産(設備・什器等)の計算
    >( 設備・什器等共済掛金(DB) + 設備・什器等その他共済掛金(DB) ) x 設備適用率
- 動産(商品・製品等)の計算
    >( 商品・製品等共済掛金(DB) + 商品・製品等その他共済掛金(DB) ) x 商品適用率

### 適用率

CSV1はCSVのテーブルから取得する値（物件情報,級別,築年数）※動産は築年数が不要
CSV2はCSVのテーブルから取得する値（物件情報,級別,築年数）※動産は築年数が不要

- 基本形
    > **ここが変わる** x 長期率[CSV2]
- 建物適用率
     >  (建物その他割引 + 建物総合割増[CSV1]) x 実損払係数[DB] x おすすめ契約期間の年数に長期率[CSV2]
- 家財適用率
     >  (動産その他割引 + 家財総合割増[CSV1]) x おすすめ契約期間の年数に長期率[CSV2]
- 設備・什器等適用率
     >  (動産その他割引 + 設備総合割増[CSV1]) x 実損払係数[DB] x おすすめ契約期間の年数に長期率[CSV2]
- 商品・製品等適用率
     >  (動産その他割引 +　商品総合割増[CSV1]　+ 動産割増[DB]) x おすすめ契約期間の年数に長期率[CSV2]

### その他割引の計算

DBはデータベースに入る値
CSVはCSVのテーブルから取得する値（物件情報,級別,築年数）※動産は築年数が不要

- 基本形
    > ( **基本率** + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB] ※小数点第 2 位に四捨五入

- 物件情報が「住宅」「普通」の**建物**その他割引
    > ( 建物の基本率[CSV] + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB]

- 物件情報が「工場」の**建物**その他割引
    > ( 建物の基本率[DB] + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB]

- 物件情報が「住宅」「普通」の**動産**その他割引
    > ( 動産の基本率[CSV] + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB]

- 物件情報が「工場」の**動産**その他割引
    > ( 動産の基本率[DB] + 職業割増[DB] + 作業割増[DB] ) x その他割引[DB]

## おすすめ契約の1年契約の場合よりの計算

- 総合共済掛金の計算 x おすすめ契約期間の年数 - おすすめ契約の共済掛金の計算
    >※総合共済掛金の計算 は 総合共済掛金合計計算式一覧を参照
