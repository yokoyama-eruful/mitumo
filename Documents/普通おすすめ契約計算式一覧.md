# 普通おすすめ契約計算式一覧

■おすすめ契約の共済掛金の計算
不動産(建物)の計算 + 動産(家財)の計算 + 動産(設備・什器等)の計算 + 動産(商品・製品等)の計算

・不動産(建物)の計算
-建物共済掛金(DB) x ( 建物その他割引 x 実損払い係数(DB) ) x おすすめ契約期間の年数に応じた料率(長期率)
 -建物その他割引 = ( 基本率(建物) + 職業割増(DB) + 作業割増(DB) ) x その他割引(DB)

・動産(家財)の計算
-家財共済掛金(DB) x ( 動産その他割引 x おすすめ契約期間の年数に応じた料率(長期率) )
 -動産その他割引 = ( 基本率(動産) + 職業割増(DB) + 作業割増(DB) ) x その他割引(DB)

・動産(設備・什器等)の計算
-( 設備・什器等共済掛金(DB) + 設備・什器等その他共済掛金(DB) ) x ( 動産その他割引 x 実損払係数(DB) ) x おすすめ契約期間の年数に応じた料率(長期率)
 -動産その他割引 = ( 基本率(動産) + 職業割増(DB) + 作業割増(DB) ) x その他割引(DB)

・動産(商品・製品等)の計算
-( 商品・製品等共済掛金(DB) + 商品・製品等その他共済掛金(DB) ) x ( 動産その他割引 x 動産割増(DB) ) x おすすめ契約期間の年数に応じた料率(長期率)
 -動産その他割引 = ( 基本率(動産) + 職業割増(DB) + 作業割増(DB) ) x その他割引(DB)

■おすすめ契約の1年契約の場合よりの計算
-普通共済掛金の計算 x おすすめ契約期間の年数 - おすすめ契約の共済掛金の計算

※普通共済掛金の計算 は 普通共済掛金合計計算式一覧を参照
